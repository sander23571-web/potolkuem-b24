## Из ревью 30.08.2026 — доразобрано

51. Решено 30.08 (по подсказке владельца — верный угол зрения через Сделку) — «Реализация по
    складам»: найден полный REST-путь без Trino/SQL Lab: `crm.deal.productrows.get` (STORE_ID +
    XML_ID=`sale_basket_{id}`) → `sale.basketitem.get` (orderId) → `sale.order`/`sale.shipment`
    (`deducted='Y'`, сумма, дата). Проверено конец-в-конец на реальной сделке 558. Настоящий
    документ реализации в Б24 — `sale.shipment.deducted`, не `catalog.document` (там его и не
    может быть — расследование 27.08 смотрело не туда). Оговорка: на 40+ проверенных сделках
    везде `STORE_ID=4` (Офис) — исторические данные покажут только «Офис», пока склад не начнут
    проставлять верно. **Решение владельца:** корректный склад (реальную точку) при оформлении
    сделки прописывает Ответственный за сделку — это процессное решение. Осталось: (а)
    инструкция для ответственных менеджеров, (б) дашборд «Реализация» на этом REST-пути.
52. Готово — «стоимость м² аренды/оклейки» (Выставки): нашёл на СП «Договоры» (1078) уже
    существующее поле `ufCrm30UnitPrice` («Стоимость за единицу, руб.») рядом с «Общая сумма
    договора» — то есть если аренда/оклейка выставки оформляется договором, цена за м² уже
    может там храниться, отдельное новое поле на Выставках может не понадобиться (площадь на
    Выставках уже есть — `ufCrm12_1784733087`). На «нал/безнал» аналога не нашлось нигде —
    остаётся новым полем на сделке, если понадобится.
