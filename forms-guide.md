# CRM-формы «Потолкуем?» — инструкция по созданию

> Интерфейс актуален для Битрикс24 2025–2026 (новый конструктор форм)

---

## Как попасть в раздел форм

**CRM → Продажи → Каналы продаж → CRM-формы**

(Альтернативный путь в некоторых версиях: **CRM → Интеграции → CRM-формы**)

Нажмите **«Добавить»** — откроется выбор сценария.

---

## Структура нового конструктора

После выбора сценария слева — панель с разделами:

| Раздел | Что настраивается |
|--------|-------------------|
| **Поля формы** | Добавить / удалить / переупорядочить поля |
| **Соглашения** | Чекбокс согласия на обработку данных |
| **Сущности в CRM** | Что создаётся при отправке формы |
| **Другие настройки** | Название формы, ответственный |
| **Дизайнер формы** | Тема, цвета, шрифт |
| **Заголовок и кнопка** | Текст над формой и на кнопке отправки |
| **Действия после отправки** | Сообщение / редирект / открыть заново |
| **Правила показа полей** | Условная логика (показать поле если...) |
| **Защита от спама** | CAPTCHA |

**Ключевой раздел — «Сущности в CRM»**: здесь выбирается, что будет создано при заполнении формы. Доступные варианты:
- Лид
- Сделка + Контакт/Компания
- **Смарт-процесс** → выбрать конкретный из списка

## Форма 1: Отчёт амбассадора

**Что создаёт:** новый элемент в смарт-процессе **Мероприятия** (стадия «Закрытие»).

> Логика: амбассадор заполняет форму после выставки → в системе появляется карточка с данными → менеджер связывает её с карточкой мероприятия или переносит данные.

### Шаги создания

1. CRM → Продажи → Каналы продаж → CRM-формы → **Добавить**
2. Сценарий: **Индивидуальная настройка** (или «Экспертный режим»)
3. Раздел **«Сущности в CRM»** → выбрать **Смарт-процесс** → **Мероприятия**
4. Раздел **«Поля формы»** → добавить поля:

| Поле в форме | Тип | Обязательное |
|---|---|---|
| Название мероприятия | Строка | Да |
| Дата проведения | Дата | Да |
| Количество посетителей стенда | Число | Да |
| Собрано контактов | Число | Да |
| Продано игр на месте | Число | Нет |
| Что понравилось / что улучшить | Текстовая область | Нет |
| Оценка мероприятия (1–5) | Число | Да |
| Имя амбассадора | Строка | Да |

5. **Соглашения** → добавить чекбокс согласия
6. **Другие настройки** → название: «Отчёт амбассадора»; ответственный: менеджер
7. **Заголовок** → «Отчёт о мероприятии» / кнопка → «Отправить отчёт»
8. **Действия после отправки** → «Сообщение»: «Спасибо! Данные приняты.»
9. Сохранить → получить **публичную ссылку**

> Ссылку вставить в задание амбассадора в Коллабе.

## Форма 2: Первый контакт на стенде (планшет)

**Что создаёт:** лид → воронка **B2C Розница**.

> Форма открыта на планшете на стенде. Посетитель заполняет сам или амбассадор помогает.

### Шаги создания

1. CRM-формы → **Добавить** → сценарий: **Индивидуальная настройка**
2. **«Сущности в CRM»** → **Лид**
3. **«Поля формы»** → добавить:

| Поле | Тип | Обязательное |
|---|---|---|
| Имя | Строка | Да |
| Телефон | Телефон | Да |
| Email | Email | Нет |
| Какая игра заинтересовала | Строка (или список) | Нет |
| Откуда узнали о нас | Строка | Нет |

4. **Другие настройки** → название: «Контакт с выставки»; источник: «Выставка»; ответственный: менеджер продаж
5. **Дизайнер** → увеличить шрифт (для планшета), контрастная тема
6. **Действия после отправки** → **«Форма откроется заново»** (важно: чтобы следующий посетитель мог заполнить без перезагрузки)
7. Сохранить → получить **публичную ссылку**

> Открыть ссылку в браузере планшета и добавить в закладки / на экран.

## Форма 3: B2B-заявка

**Что создаёт:** лид → воронка **B2B Корпоратив** или **B2B Образование** (в зависимости от ответа).

> Форма на сайте или отправляется по запросу. Корпоративный клиент заполняет сам.

### Шаги создания

1. CRM-формы → **Добавить** → сценарий: **Индивидуальная настройка**
2. **«Сущности в CRM»** → **Лид**
3. **«Поля формы»** → добавить:

| Поле | Тип | Обязательное |
|---|---|---|
| Имя и фамилия | Строка | Да |
| Компания / организация | Строка | Да |
| Должность | Строка | Нет |
| Телефон | Телефон | Да |
| Email | Email | Да |
| Тип организации | Список: Бизнес / Школа / Вуз / Другое | Да |
| Примерное количество комплектов | Число | Нет |
| Задача (тимбилдинг, подарки, обучение...) | Текстовая область | Нет |
| Удобное время для звонка | Строка | Нет |

4. **Другие настройки** → название: «B2B-заявка»; ответственный: менеджер
5. **Заголовок** → «Корпоративный заказ» / кнопка → «Отправить заявку»
6. **Действия после отправки** → сообщение: «Спасибо! Мы свяжемся с вами в течение одного рабочего дня.»
7. Сохранить → получить **публичную ссылку**

> После получения лида менеджер вручную переносит его в нужную воронку (корпоратив или образование) исходя из ответа «Тип организации». Это можно автоматизировать позже.

## Форма 4: Анкета новой точки продаж

**Что создаёт:** новый элемент в смарт-процессе **Точки продаж**.

> Заполняется менеджером после договорённости с партнёром — или партнёром самостоятельно по ссылке.

### Шаги создания

1. CRM-формы → **Добавить** → сценарий: **Индивидуальная настройка**
2. **«Сущности в CRM»** → **Смарт-процесс** → **Точки продаж**
3. **«Поля формы»** → добавить:

| Поле | Тип | Обязательное |
|---|---|---|
| Название точки | Строка | Да |
| Тип (книжный / кафе / музей / коворкинг / другое) | Список | Да |
| Адрес | Строка | Да |
| Контактное лицо | Строка | Да |
| Телефон | Телефон | Да |
| Email | Email | Нет |
| Условия работы | Список: Реализация / Закупка / Депозит | Да |
| Комиссия % | Число | Нет |
| Первая партия — количество | Число | Нет |
| Комментарий | Текстовая область | Нет |

4. **Другие настройки** → название: «Анкета партнёра»; ответственный: менеджер
5. **Заголовок** → «Заявка на сотрудничество» / кнопка → «Отправить анкету»
6. **Действия после отправки** → сообщение: «Спасибо! Мы оформим карточку и свяжемся с вами.»
7. Сохранить → получить **публичную ссылку**

---

## Как получить публичную ссылку

После сохранения формы:
- В списке CRM-форм найдите нужную форму
- Нажмите **«...»** (три точки) или кнопку **«Ссылка»** рядом с формой
- Скопируйте публичную ссылку — она открывается в браузере без входа в Битрикс24

Ссылку можно:
- Отправить амбассадору
- Открыть на планшете
- Разместить на сайте
- Вставить в QR-код

---

## Важные замечания

**Поля пользователя (UF_CRM_...):** Кастомные поля смарт-процессов появятся в конструкторе формы автоматически — они доступны для добавления в разделе «Поля формы» при выборе соответствующей сущности. Ищите их в списке под стандартными полями.

**Дубликаты:** Для форм на планшете (Форма 2) рекомендуется в «Экспертной настройке» выбрать **«Объединять дубликаты»** — чтобы не создавать новый лид, если человек уже есть в системе.

**Тест перед использованием:** Обязательно заполните каждую форму сами после создания и проверьте, что запись появилась в нужном разделе CRM.
